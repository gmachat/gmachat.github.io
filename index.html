A homemade React-style state layer in about 120 lines.

Chute.js is a zero-dependency reactive state-management framework created for this portfolio. Its immutable store drives the navigation and card modals you interact with across the page.

  • Named actions and predictable immutable state updates
  • Selector-driven components that render only when their state changes
  • Microtask-batched updates, subscriptions, and lifecycle cleanup
