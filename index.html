Code Room
A final group project for my Code Platoon cohort, Code Room is a lightweight collaborative coding platform for instructors, students, and anyone who wants to solve challenges with others. Instructors write a challenge and share a link to a page with a real-time collaborative IDE, functioning compiler, and video chat. Submissions remain available to the instructor. The project uses a Django backend, React frontend, and Firebase real-time database.
